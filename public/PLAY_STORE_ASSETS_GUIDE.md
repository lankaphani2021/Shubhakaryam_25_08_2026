# Play Store Image Assets Creation Guide - Shubhakaryam

## 🎨 Required Images for Google Play Store

### 1. **App Icon (512×512px PNG)** - REQUIRED ⭐
- **Size:** Exactly 512×512 pixels
- **Format:** PNG with transparency
- **Design:** Diya/flame icon with saffron-maroon gradient
- **Text:** "SHUBHAKARYAM" + "Pooja Booking" subtitle
- **Template Provided:** icon-template.svg

### 2. **Feature Graphic (1024×500px)** - RECOMMENDED ⭐⭐
- **Size:** 1024×500 pixels
- **Format:** PNG or JPG
- **Purpose:** Promotional banner in Play Store
- **Content:** App name, tagline, cultural elements

### 3. **Screenshots (2-8 images, 1080×1920px)** - REQUIRED ⭐⭐⭐
- **Size:** 1080×1920 pixels (portrait orientation)
- **Format:** PNG or JPG
- **Content:** Actual app screens (no phone frames)
- **Required Screens:**
  - Home page with services
  - Services listing
  - Booking page
  - Priest profiles
  - My Bookings
  - Astrology services
  - Navagraha Daan
  - Profile page

## 📋 Step-by-Step Creation Process

### **App Icon Creation (5-10 minutes):**

#### **Using Canva:**
1. Go to canva.com
2. Search "App Icon"
3. Select 512×512px template
4. **Background:**
   - Add gradient: #FF6B35 → #DC2626 → #991B1B
   - Apply rounded corners (radius: 115px)
5. **Main Element:**
   - Search "diya" or "flame icon"
   - Add gold diya with flame (#FFD700)
   - Center and scale appropriately
6. **Text:**
   - Add "SHUBHAKARYAM" (white, bold, 48px)
   - Add "Pooja Booking" (white, 20px)
7. **Export:**
   - Download as PNG 512×512
   - Ensure transparency is maintained

#### **Using Favicon.io:**
1. Go to favicon.io
2. Click "Text" tab
3. Enter "SH"
4. Choose colors: Red/Orange gradient
5. Customize with your preferred style
6. Download 512×512 PNG

### **Feature Graphic Creation (10-15 minutes):**

#### **Using Canva:**
1. Create custom design: 1024×500px
2. **Background:**
   - Gradient: Saffron (#FF6B35) to Maroon (#DC2626)
   - Add subtle traditional pattern overlay
3. **Main Content:**
   - Add "Shubhakaryam" text (120px, bold, white)
   - Position: Left-center
   - Tagline: "Authentic Telugu Poojas" (40px, gold)
4. **Decorative Elements:**
   - Add small diya icons
   - Traditional border patterns
   - Cultural symbols
5. **Right Side:**
   - Add phone mockup showing app
   - Or service icons (pooja, homam, astrology)
6. **Export:** PNG or JPG, 1024×500

### **Screenshots Creation (30-45 minutes):**

#### **From Live App:**
1. **Prepare Your App:**
   - Open app on phone
   - Navigate to key screens
   - Ensure good lighting/content

2. **Take Screenshots:**
   - Home page (services overview)
   - Services listing (all categories)
   - Individual service page
   - Booking flow
   - Priest profiles
   - My Bookings
   - Astrology services
   - Navagraha Daan

3. **Edit Screenshots:**
   - Crop to 1080×1920px
   - Remove status bars/phone frames
   - Ensure consistent brightness
   - No text overlays in other languages

#### **Creating Mock Screenshots:**
1. **Use Screenshot.rocks:**
   - Select device type
   - Upload your app screens
   - Customize backgrounds
   - Download 1080×1920 PNG

2. **Use Canva:**
   - Create 1080×1920 design
   - Add app screen content
   - Add captions/text overlays
   - Download as PNG
