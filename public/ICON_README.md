# PWA Icon Generation

This directory contains the app icons for Progressive Web App functionality.

## Required Icons

1. **android-chrome-192x192.png** (192x192) - Android home screen icon
2. **android-chrome-512x512.png** (512x512) - Android splash screen icon  
3. **apple-touch-icon.png** (180x180) - iOS home screen icon
4. **favicon-32x32.png** (32x32) - Standard favicon
5. **favicon-16x16.png** (16x16) - Small favicon
6. **favicon.ico** - Legacy favicon

## Icon Specifications

- **Format**: PNG with transparency
- **Colors**: Use the brand gradient (saffron to maroon) with the flame icon
- **Design**: Flame icon on circular gradient background
- **Safe Area**: Maintain 10% safe margin for cropping

## Tools for Generation

You can use these tools to generate the icons from a source image:

- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator)
- [Favicon.io](https://favicon.io/)

## Current Status

The icon files need to be created and added to the `/app/public/` directory.
